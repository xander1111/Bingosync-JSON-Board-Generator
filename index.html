Simple Generator

Generates JSON for the fixed board or randomized options.

Note that a fixed board must have exactly 25 goals, while a randomized board needs at least 25.

Difficulty Balanced JSON Generator

Generates JSON for the SRL v5 or Isaac options.

Goals that share types won't appear in the same row (only works with SRL v5). This usually requires more goals to work. Multiple types can be used by seperating them with a comma (ex: type1, type2, etc.).
